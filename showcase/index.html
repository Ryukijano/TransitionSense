TransitionSense

TimeNet Online Hackathon 2026 — temporal-language-model fine-tuning vs conventional depth models for postural-transition recognition on unseen subjects.

Hypothesis. Does fine-tuning a temporal language model (OpenTSLM-SP on Gemma 3 270M) improve recognition of brief postural transitions compared with 1-D CNN and patch-Transformer baselines, evaluated strictly on subjects absent from training?

Dataset

UCI HAPT v2.1 via the uci/hapt TimeNet connector: 61 continuous trials, six IMU channels (accelerometer in g, gyroscope in rad/s) at 50 Hz, 1,214 scoped classification tasks, 12 classes (6 activities + 6 postural transitions). Windows: 128 samples, stride 64, centre-sample labelling. All splits are subject-disjoint; the test split uses the official UCI held-out subjects.

Method

  • Baselines: 1-D ResNet and patch Transformer trained on the same windows with class-balanced cross-entropy; best checkpoint by validation macro-F1.
  • TSLM: OpenTSLM-SP — frozen Gemma 3 270M backbone, trainable CNN patch encoder + MLP projector, optional LoRA (r=16) on the LLM; trained with teacher-forced answer loss on the same windows.
  • Evaluation: macro-F1 over all 12 classes and over the six transition classes only, on 9 unseen test subjects (3,718 windows). Generative models report a parse rate; unparseable outputs count as errors.
